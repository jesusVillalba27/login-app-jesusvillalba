# Login App - Jesús Villalba

## Estrategia de ramificación
Para este proyecto se ha elegido la estrategia **GitHub Flow**.
**Justificación:** Es ideal para proyectos web pequeños y despliegues continuos. Mantiene la rama `main` siempre estable y lista para producción. Todo el desarrollo nuevo se hace en ramas cortas (`feature/*`) que se integran a `main` mediante un Pull Request.
